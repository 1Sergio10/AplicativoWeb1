Sobre el proyecto

Una primera experiencia para convertir ideas en una página real.

Soy estudiante y desarrollé este sitio para practicar cómo se estructura, diseña y presenta una página web de una sola página.

El objetivo es aplicar los conocimientos vistos en clase de manera ordenada: usar etiquetas semánticas, organizar el contenido con Flexbox, crear un formulario accesible y adaptar la experiencia a diferentes tamaños de pantalla.
